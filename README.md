# 📱 Phone-book (Spring Boot + REST API + SQL)

Простой и эффективный REST API сервис для управления списком контактов (телефонной книгой), построенный на современном стеке технологий Java и Spring Framework.

## 🚀 Технологический стек
* **Java 17** (или твоя версия Java)
* **Spring Boot 3.x** (Web, Data JPA, Validation)
* **SQL / Hibernate** (Автоматическое управление сущностями и базой данных)
* **Lombok / MapStruct** (опционально, если используешь для маппинга)

## 🛠 Функционал и API Эндпоинты

Приложение предоставляет стандартный набор CRUD-операций для работы с контактами:

* `POST /api/contacts` — Создание нового контакта (встроена валидация данных и защита от создания учетных записей администратора).
* `GET /api/contacts` — Получение полного списка сохраненных контактов.
* `GET /api/contacts/{id}` — Поиск конкретного контакта по его уникальному ID (возвращает 404, если контакт не найден).
* `DELETE /api/contacts/{id}` — Безопасное удаление контакта из базы данных по ID.
* `GET /run-cfg` — Тестовый эндпоинт для проверки работы внутренних сервисов.

## ⚙️ Особенности реализации
1. **Валидация входящих данных:** Использование спецификации `jakarta.validation` для проверки корректности передаваемых DTO (`ContactFto`).
2. **Безопасность бизнес-логики:** Реализована кастомная проверка на уровне контроллера, запрещающая регистрацию системных имен.
3. **Асинхронность:** Включена поддержка асинхронного выполнения задач с помощью аннотации `@EnableAsync`.
4. **Слоистая архитектура:** Четкое разделение ответственности между контроллерами (`@RestController`), репозиториями (`@Repository`) и сервисным слоем (`ContactService`).
